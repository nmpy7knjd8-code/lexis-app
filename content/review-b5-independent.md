# Lexis batch 5: independent review

Scope: 53 drafted cards (content/b5_cards.py). Every quote was checked against its source text with verify_quotes.py (exact match, fuzzy match for OCR files), and the context claims were checked against the sources and standard references.

## Removed
- **t-condamne-libre**: the quote ("je suis condamné à être libre") already appears on t-engagement. The card is a duplicate.
- **t-revolte**: the existing t-absurde card already explains Camus's revolt and Sisyphus, so this card is a near-duplicate.

## Fixed
- **t-adiaphora**: the draft quoted Diogenes Laertius 3.105, which comes from the Platonic divisions and is not Stoic doctrine. It now quotes the Stoic list of indifferents at 7.102.
- **t-pathos-der-distanz**: the elision used "[…]", which the verifier does not accept. Changed to " … ", and the quote now verifies.
- **t-homo-mensura**: "Protagoras' own book teaches nothing" overstated the Theaetetus. The text now gives Socrates' actual objection: why pay Protagoras to teach (161d–e).
- **t-prolepsis**: Epictetus says *education* is learning to apply preconceptions (Discourses 1.22), not "philosophy". Wording corrected.
- **t-guter-wille**: the quote was only a fragment ("als allein ein guter Wille"). After stripping the korpora.org line numbers, it is now the full opening sentence of AA IV 393.
- **t-regelfolgen**: the draft example did not match the text. It now uses the actual pupil example from PI §185 (1000, 1004, 1008).
- **t-hyperreel**: "television news" was not Baudrillard's example. Changed to reality television (the Loud family), alongside Disneyland.
